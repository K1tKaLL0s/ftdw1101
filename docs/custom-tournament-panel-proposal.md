# 自定义赛事面板后续方案

先做“选择模板 → 调整参数 → 预演 → 发布”的表单，复用本次的创建页、现有 `/schedule` 五时段日历、报名/报到和生产账号权限。时段外赛事保留同日展示。模板为瑞士预选加 Top Cut、伪双败、三幻神不分组及 A/B；不让用户填写任意脚本或 SQL。

首版只开放已经有算法与测试支持的参数：瑞士轮数 3–7、晋级人数、赛事人数与时区、比赛时间、公开规则与同分处理；三幻神沿用已确认的计分、生命和复活流程。尚未明确的自动裁定项以“裁判登记”显示，不能通过填一个数字冒充已支持的规则。

每次修改参数立即校验人数、晋级和阶段依赖，并展示生成的规则说明、预计轮次/比赛数和赛程。预演使用虚拟选手验证 2/3/5/8/16 人、奇数轮空、退赛、平局、双方负、晋级线同分及瑞士配对死锁；遇死锁展示已有的显式人工恢复流程。

发布前保存规则版本与公开文本；开赛锁定，不回写已公布轮次或已启动阶段。赛中只允许已有的记分、库存、资格及人工恢复命令，并要求操作原因、权限检查、幂等及影响提示。新计分公式或新胜负条件，先增加对应领域算法与回归案例，再开放配置。

完成上述表单后，再根据实际校赛使用记录决定是否需要可视化阶段编排。现阶段不建拖拽式通用赛制引擎，避免产生界面允许配置、引擎却无法正确执行的规则。
